# Digital Store

Projeto final de e-commerce em React + TypeScript + Tailwind, pronto para deploy no Vercel.

## Tecnologias
- React
- Vite
- TypeScript
- Tailwind CSS
- React Router

## Funcionalidades
- Home com slider de banners
- Listagem de produtos com filtros e busca
- Página de detalhes do produto
- Carrinho com localStorage
- Login simulado
- Checkout
- Design responsivo e moderno

## Como rodar
```bash
npm install
npm run dev
```

## Deploy no Vercel
- Conecte o repositório ao Vercel
- Framework: Vite
- Build Command: npm run build
- Output Directory: dist

## Observação
O arquivo `vercel.json` foi incluído para garantir o funcionamento correto das rotas em produção.
